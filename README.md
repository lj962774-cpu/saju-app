# ✨ 나의 사주 캐릭터 찾기

생년월일만 넣으면 나만의 사주 캐릭터부터 재미로 보는 운세까지 한 번에 확인하는 웹앱입니다.
누구나 쉽게 이해할 수 있도록 어려운 한자 대신 캐릭터·이모지·쉬운 설명 위주로 구성했습니다.

## 주요 기능

- **사주 캐릭터 카드**: 태어난 날의 천간(일간)을 "맑은 이슬 💧", "큰 나무 🌳" 같은 캐릭터로 표현
- **재미로 보는 운세**: 재물운·연애운·학업운·인생 황금기·상징 동물·개쩌는 지수·적성 매칭·회사 존버 지수·로또 확률
- **신살(神殺)**: 도화살·역마살·화개살·천을귀인 등 "무슨 살"을 쉬운 설명 + 근거와 함께
- **대운(大運)**: 10년 단위 운의 흐름을 인터랙티브 타임라인으로, 각 시기별 테마 설명
- **오행 밸런스**: "목 기운이 강하면 무슨 의미인지"를 근거와 함께 쉽게 해석
- **궁합**: 상대방 생년월일로 오행 기반 케미 확인 (서로 부족한 기운 보완 여부 반영)
- **전문가용 원국표**: 정통 사주 8글자 한자표는 접이식으로 제공

> 계산 정확도를 위해 24절기 기준 월주 계산과 양력→간지 변환을 사용합니다.
> 재미 운세는 생년월일을 시드로 한 결정론적 값이라, 같은 생일이면 항상 같은 결과가 나옵니다.

## 기술 스택

- React + TypeScript + Vite
- [lunar-javascript](https://github.com/6tail/lunar-javascript) — 절기/음력/사주(八字) 계산

## 실행 방법

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 주의사항

이 앱의 해석 내용은 전통 명리학 이론에 기반한 **재미·참고용** 정보이며, 의학적·법적·재정적 조언을 대체하지 않습니다. 로또 확률 등 일부 콘텐츠는 순수 오락용 수치입니다.
